# 多变量联合反演的共享与专属表征

## 实验结论

在相同训练预算和相近卷积权重数下，1×1 专家换回 3×3 空间专家，SM、ET 的站点 R 从 0.5814、0.8432 提高到 0.5918、0.8474，两个 RMSE 也同时降低。这支持让两个变量共享可利用邻域的信息。两个 checkpoint 的冻结干预均显示，ET 更依赖共享专家，SM 更依赖私有专家；完全切断 SM 对共享专家的访问也损害其相关性。模型内部的专家分工可以验证，每个专家的物理含义仍待识别。

在相同权重上局部计算 SM 门控，两份模型的 SM RMSE 均小幅下降，ET 逐项相同。联合重训时 SM R 增至 0.6081，ET R 却从同期对照的 0.8474 降至 0.8338。多个变量同时受益取决于共享信息是否有用；单变量调整的代价取决于它是否也改变其他变量依赖的表征。任务兼顾与跨地区泛化需要分别测量。[实验及不确定性](validation/CGC_MECHANISM_20261121.md)

## 从单层 CGC 到可堆叠的空间专家单元

**为什么保留 CGC。** 它给多个变量一个低成本的选择：任务可以使用对各变量都有价值的邻域特征，也可以选择只为自己优化的专家。两个训练运行的 ET 分支分别给同一个共享专家 88% 和 95% 的平均权重，SM 分支则分别给私有专家 87% 和 88%。在历史权重上切除共享路径，站点总 ET 的 RMSE 从 0.959 升至 2.084 mm/day。允许共享、限制其他任务直接改动本任务私有专家，这两个结构约束比专家编号更有科学意义。现有实验不能把门控变化完全归因于某个水文过程。

**为什么局部 SM 门控有效。** 原门控给全图块同一组专家权重，因而相距很近但状态不同的两个位置只能使用相同的混合系数。改为逐位置计算后，专家仍可利用 3×3 邻域，测点附近的状态却可以改变该处的混合比例。这个改动不增加参数。冻结模型的两个配对实验支持小幅降低 SM RMSE，ET 推理路径逐项相同。这一归纳偏置来自测点监督和干预证据；整块 ET 门控在此作为已有强基线，并不代表通量塔足迹恰好等于整个图块。

### 一个重复单元

输入是一张公共状态图 s 和覆盖、SM、ET 各一张任务状态图 t。首次进入时，四条流都读同一个按目标时间对齐的 FM 状态。一个单元只做三步。

1. 两个共享空间专家从 s 各提取一张图，一个任务私有空间专家从本任务 t 提取一张图。专家沿用 CGC 的通道投影与 3×3 空间残差卷积。
2. 每个任务采用同一空间门控。以当前任务有效位置的状态均值 μ 和当前位置的状态 h(p) 构造 z(p) = μ + α × (h(p) − μ)，再用线性层和 softmax 混合两个共享专家和自己的私有专家。α = sigmoid(β)，每个任务组一个 β，均从 0 开始，初始 α 为 0.5。各块复用这三个标量。α 接近 0 对应整块门控，接近 1 对应局部门控。α 描述门控输入对局部差异的敏感程度，真实监督足迹由各自的观测算子定义。
3. 本任务的混合图构成它的更新提议，两个共享专家的均值构成公共流的更新提议。所有流从上一层同步读取。私有流不能写回公共流；共享专家仍可通过各任务的损失获得梯度。

### 把同一单元堆叠成 FM 微调模型

    S1 / S2 / Landsat 五个时间槽
      → OlmoEarth + 共享 LoRA，第 4/8/12 层特征按目标时间融合
      → 第一次空间专家提取（256 → 64 通道，统一空间门控）
      → 64 通道空间专家单元，残差更新
      → 原有空间读出与七个物理输出，派生面积加权总 ET

首层采用原空间专家与任务读出契约。第二块读取第一块的任务状态，按 u_new = u + γ × (proposal − u) 做残差更新。γ 初始为零，因此相同权重下初始映射等于单块统一门控模型。两块的通道不同，专家和门控线性层分别学习，三个空间混合标量跨块共用。以后若增加第三块，可重复调用第二块，保持参数量相同。

**可检验假设。** 在所有任务上统一利用局部和整块信息，可能在保留共享收益的同时改善站内时间变化预测；第二块可依据已经分化的任务状态再次选择专家。α 学到的数值和线性门控、专家输出共同决定预测，需要实际干预才能解释。固定门控的干预证据与统一门控的整模型筛选结果分别报告。

**最小对照。** 先比较固定门控单块与统一可学习门控单块，保持其余设置相同。若值得保留，再比较同一统一门控的一块与两块，并在训练好的两块模型上关闭残差步长做配对验证。优先报告站点等权 RMSE、站内异常 R 及站间 R，同时检验 ET 是否维持。使用配对种子和冻结的开发划分。

最新入口为[两块统一门控配置](../configs/hydrostate_joint_adaptive_cgc.py)与[空间专家单元](../hydrostate/models/cosa/cgc.py)。[固定门控三层原型](../configs/hydrostate_joint_recurrent_cgc.py)可用于历史比较。

### 单块对照与两块推理干预

单块作业 38881（代码 `4295c89`）完成 6 轮，耗时 7 小时 16 分。与两块运行配置相比，除输出目录外只改 depth。第 6 轮以 site_score −0.6585 获选，站点有效数量相同。单块最终 α 为覆盖 0.49796、SM 0.49915、ET 0.49903。两块版的四项站点指标均略优于单块版。这是同一开发划分的单种子对照，无法判定可复现优势。

作业 38882 直接复用两块最佳权重，关闭第二块使 SM、ET 的 Pearson R 分别变化 +0.0000133、−0.0000096，RMSE 分别变化 +0.0000031 m³/m³、+0.0001915 mm/day。将三个 α 固定为 0.5 后，两项 R 的变化绝对值均低于 0.000001。四项指标在两次干预中的配对空间组 bootstrap 差值区间均跨零。这表明该检查点推理时对第二块的依赖很小，无法将独立训练结果的差异归因为第二块直接修正了预测。日志与配对表位于同一实验根目录的 `cgc_adaptive_one` 和 `adaptive_interventions`。

### 历史站点对照

对已完成选模的历史原版 CGC，预先固定比较整块门控与同权重局部 SM 门控，在正式站点 test 划分运行一次。两种预测共享 encoder、窗口、观测索引和空间算子。按任务核对与 train/validation 的空间组和物理组隔离。跨任务允许共址，分别注明其适用范围。新组件开发不得用这份测试结果选择参数或阈值。

按原始标签的站点标识合并同站同窗多个观测，分别平均配对的预测与标签。报告逐站窗口 RMSE、站点等权的观测期均值之间的 Pearson R，以及在每站分别减去预测均值与观测均值后的合并异常 R。后者仅用至少两个不同窗口的站点；另报窗口数、跨年站点数和按空间组整组重采样的配对区间。站点均值是已抽样日期的均值，不同站点的年代和季节可能不同；异常包含季节循环。这里衡量已留出站点的泛化，不能据此外推出未观测气候区或独立逐像素真值。
