# 历史记录

本目录保留此前的数据准备、架构对比、部署与实验记录，用于解释已有结果。
其中的“当前”、任务状态、样本数量和命令属于记录当时，不作为最新执行依据。

- 当前方案：[RETRIEVAL_PIPELINE](../RETRIEVAL_PIPELINE.md)
- 当前执行：[DATA_PREPARATION](../DATA_PREPARATION.md)
- 当前结构：[REPOSITORY_STRUCTURE](../REPOSITORY_STRUCTURE.md)

原始共享解码器、轻量三阶段和多层融合模型的历史说明见
[MODEL_ARCHITECTURES](MODEL_ARCHITECTURES.md)。对应配置在 `configs/experiments/legacy/`。
`*_BEFORE_RETRIEVAL.md` 保留本轮整理前的完整记录，历史旧格式不自动转换。
