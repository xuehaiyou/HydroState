# SM 误差来源的受控实验方案

日期：2026-09-25。范围：samples_v2 / gee_20260923_all、作业 4107932。
本文件是实验设计，不代表已实现或提交训练。原训练和不可变数据保持不变。

## 1. 已知事实与待区分解释

- 有效 SM 训练/验证窗口为 1458/165；按生成代码的 5° 空间块分别为 198/32 块，覆盖 18/17 个 climate_class。
- 三任务分别按全局有效监督数求平均，并使用训练标准差标准化；WF 像元数大不直接放大其任务损失。
- 已完成的第 20/32 轮诊断不支持 WF 梯度独占共享层，但不是全模型 AdamW 因果试验。
- 已发现批次依赖，必须先解决；已有检查点结果只作定位材料。
- 输入已有四个时间槽：相对采样目标日 [-63,-47)、[-47,-31)、[-31,-15)、[-15,1) 天；每槽可有 S1/S2/Landsat，实际日期不同。
- 最终有效 SM 训练窗口的标签日期偏移（天）：-3:26、-2:30、-1:525、0:631、1:189、2:38、3:19；验证为 -2:2、-1:58、0:77、1:22、2:5、3:1。
- 窗口为约 1.2 km × 1.2 km；SM 监督是窗口预测均值匹配窗口中心 SMAP 产品值，不是完整原生 SMAP 足迹平均。
- 当前标签监督是产品拟合。缺少独立地面真值时，不能把产品误差当作真实土壤水分误差，也不能估计不可约噪声下限。

需要区分：多任务负迁移、独立数据/覆盖不足、历史信息利用不足、时间或空间支持不匹配、过拟合/域偏移、优化或实现问题。这些原因可以并存。

## 2. P0：开始训练对照前的门槛

### 2.1 推理与监督一致性

复用 diagnose_multitask.py 固定样本的一致性检查，补齐 train/val 两种前向模式。
eval 下比较单样本、重复样本、混合 batch=2/16/32、重排、不同缺失模态邻居，按 sample_id 对齐。
逐层检查编码器掩码、时间 padding、模态融合和池化，定位第一个出现跨样本依赖的位置；不能仅调整 batch 使总指标相近。
用 FP32 重复推理作为参考，另报告按训练 std 标准化的预测差；建议预登记近零容差为 atol=1e-5、rtol=1e-4，若硬件数值差超限须解释并设定有依据的容差，不能放行系统性变化。
同时检查删减时间槽后 prediction_valid 与实际有效输入一致；禁止移除影像却留下原来的输入有效掩码。
修复后重新生成基线；全部实验使用同一修复版本，不用旧第 40 轮指标作为因果对照组。

### 2.2 观测与划分审计

以最终观测算子的 count>0 确定 SM 有效样本，不能只看 labels 元数据或 CSV 中存在任务行。
生成 audit.parquet：sample_id、原 split、生成代码定义的 block、climate、日期/月、SM 值、原生像元及产品日期、各模态实际观测日期/有效面积、距 SM 日期时差、窗口水体比例。
从源产品 CRS/affine 恢复原生像元 ID；同一原生像元×日期的窗口归为同一观测组。无法恢复时明确标记 unknown，不能用经纬度粗取整冒充原生 ID。
检查组内重复和跨 split 重叠；重复组不跨内层训练/评估划分，抽样和置信区间不能把它们当作独立信息。
原 test 不参加本方案。原 validation 固定用于预登记的方案比较；调参/早停使用原 train 内按空间块留出的固定内层开发集。最终确认才允许一次性使用 test。

## 3. 所有正式比较的共同协议

- 下文 7464/1458 及子集规模指原 train 的上限。实际训练池先扣除固定内层开发集，再生成比例子集并记录精确数量；所有配对采用同一内层划分。11700 更新是统一预算，不随扣除后的池大小变化。
- 从同一 OlmoEarth 预训练权重及配对随机初始化开始；不能从已有多任务检查点初始化所谓单任务基线。
- 先单种子筛查，选定比较至少 3 个配对种子。相同 seed 控制初始化、数据序列、增强；保存实际索引序列。
- 保持 world size=2、每卡 batch=16、优化器、裁剪、精度、增强及学习率更新序列相同。
- 预算按优化器更新数固定：参考现有 234 更新/轮 × 50 轮=11700 更新。先验证原训练步数，再锁定实际值。子集不能仍以 50 个子集 epoch 作为等预算。
- 筛查可用 2340 更新（10 个原始等效 epoch），但较短日程不得据此宣称最终优劣。正式比较完整预算且使用一致日程。
- 定期在完整训练集无增强 eval，报告总体、参与监督子集、训练内留出及原 validation。最后一步指标与内层开发集选择的检查点指标同时报告。
- 固定归一化：标准差只由相应训练标签估计，绝不读取原 validation/test。数据量曲线统一使用所有嵌套子集共有的最小训练子集统计量，防止大子集的标签信息通过标准差泄漏给小子集；另报告全量统计重跑的可选敏感性分析。
- 主要指标为 SM RMSE（m³/m³），辅以 MAE、bias、去偏 RMSE、R²；同时记录 WF/ET 的代价与完整训练开销。
- 原 validation 仅有 165 个 SM 窗口、32 个空间块：配对空间块 bootstrap 1000 次、按种子报告差值；额外给跨种子均值和范围，不能把不同种子/重复像元混作独立验证样本。
- 建议预登记“有实际意义的改善”为相对 RMSE 至少 5%，并且配对差值 95% CI 支持改善、至少 2/3 seeds 同方向。该阈值是本项目决策约定，不是统计定律；未达到时写证据不足，不写原因被排除。

## 4. A：是否存在多任务负迁移

| 编号 | 前向输入与序列 | 优化目标 | 用途 |
| --- | --- | --- | --- |
| A0 | 全部 7464 个训练窗口，固定原采样序列 | 当前三任务 NLL | 修复后的现实基线 |
| A1 | 与 A0 完全相同 | 仅 SM NLL | 现实训练下移除辅助任务的净效果 |
| A2 | 与 A0 相同 | 三任务标准化 MSE，相加 | 排除学习方差权重影响 |
| A3 | 与 A0 相同 | 仅 SM 标准化 MSE | 与 A2 配对验证任务组合效应 |

A0/A1 保留同一 SM 损失函数、初始化和 SM 标签序列。保留相同网络结构与前向，关闭非 SM 损失；关闭 head 的参数设为不更新，避免零梯度仍受到 AdamW 权重衰减。
所有任务组仍使用同一个 batch 序列，不能把 A1 换成每 batch 32 个 SM 样本，否则同时增加 SM 曝光量。
全局无 SM 的 batch 对 A1 是无监督步：记录发生次数；可选严格配对分析让全部组在这些位置都跳过 optimizer.step，并按有效步数统一日程。不得把局部某 rank 无 SM 当作全局无 SM。

若 A1 优于 A0，但 A3 不优于 A2，优先检查 NLL 权重/优化机制；若两个配对均稳定改善，更支持当前共享结构中的多任务负迁移。
这仍包含辅助样本上的更新影响，不直接证明“同一样本任务冲突”。必要时在相同 SM 有效窗口池追加 SM-only / SM+WF / SM+ET / 三任务，输入与 SM 曝光完全一致，记录辅助任务可用率；其中 SM+ET 仅在有 ET 标签的窗口产生 ET 损失。
梯度探针仅作解释，不以负 cosine 的比例替代验证结果。

## 5. B：数量、覆盖还是重复曝光

本批数据最多只有 1458 个已知有效 SM 训练窗口；不能声称生成更多独立标签。使用学习曲线研究从少到多恢复已有监督。

在 A3 的固定训练流中使用按原生观测组生成的嵌套 SM 标签子集：25%、50%、100%（约 365/729/1458 个窗口；受分组约束实际数量可能不同）。小组包含于大组，按空间块、月份、气候分层，随机选择只使用原 train。若已有观测重复，报告独立组数而非仅窗口数。

两种预算必须分开：

1. **固定 SM 曝光/更新预算（主要学习曲线）**：每组从自己的 SM 训练池采样，batch=32、有效更新数相同。小池会重复更多；学习率日程相同。这样比较更多独立信息与重复学习少量信息的差别。完整池的 SM-only 对照需单独训练，不能复用 A3 的稀疏标签 batch 基线。
2. **固定每个观测组重复次数（敏感性检查）**：每组观察相同遍数，大池更新更多；单列计算开销，不把其收益全部归因于信息量。

同一数量追加“较多地理块，每块较少样本”与“较少地理块，每块较多样本”的配对子集。可行时匹配月份、气候、SM 值区间和输入覆盖；不能匹配的差异明确列出。用多个子集种子重复，不能一次抽样就认定覆盖作用。

解释：固定更新下随独立数据增加而稳定改善，支持当前范围内的数据瓶颈；相同数量下更广覆盖更好，支持覆盖瓶颈。平坦曲线不证明数据无用，也不预测超过现有数据规模后的趋势。增采样仅改变频率，不能等同增加独立样本。

## 6. C：现有历史信息是否有用、模型是否正确利用时间

以 B 的完整 SM-only 训练池和标准化 MSE 为底座，固定标签、更新、初始化；每个输入版本都从头训练，不仅在已有模型上临时删帧。

| 编号 | 输入版本 | 对照解释 |
| --- | --- | --- |
| C0 | 每种模态仅保留最近一个合法观测 | 无历史基线 |
| C1 | 全部已有四槽影像与真实时间戳 | C1 优于 C0：已有历史提供有效信息 |
| C2 | C1 + 相对 SM 目标时刻的时差、缺失标记，经过小型融合支路 | 检查显式目标条件和时间对齐 |
| C2-control | 相同支路及参数量，时差置零，缺失标记保留 | 排除单纯增参带来的改善 |

SM 日期的时间语义必须定义：先核实产品 timestamp 是观测时刻还是日产品标记；若只能确定日期，采用按日的目标条件，不能假装有精确过境时间。目标日期是产品检索请求的一部分，不输入 SM 数值、质量评分或其他标签派生特征。
分别预登记两种任务之一：a. 回溯估计，允许目标日期之后的已有影像；b. 截至目标日期的估计，所有组均过滤未来影像。不能 C0 无未来而 C1 有未来后宣称历史有效。正式优先用 b；日内时间不确定时报告边界规则敏感性。
C0/C1/C2 在过滤后共同可评估的窗口上做主要配对分析，并另外报告保留率及各自全量结果。移除时槽导致空间观测支持不同，须固定同一有效像元交集作机制比较，另报告各输入版本原生支持下的实际表现；训练和验证采取一致规则。
按最近 S1/S2/Landsat 距 SM 日期时差分层评估，预登记 0–1、2–3、4–7、>7 天，稀疏组只描述。

可选时间戳负对照：在训练和评估中采用同一预登记随机化规则，打乱时间戳与影像的对应，保留可用率及日期边际分布。必须说明这是破坏时间语义的负对照，不是实际可部署方案。
不能把“交换输入数组位置但时间戳随影像一起移动”当作打乱时间信息。

C1 优于 C0 仅证明现有历史有用，不证明当前四槽仍缺信息；C2 优于 C1 且优于等参数 control，才支持时间条件表达是瓶颈。只有新增信息来源的实验才能测试降雨、灌溉等未观测驱动；当前数据没有这些输入，因此不能通过本方案排除其缺失影响。

## 7. D：过拟合、域偏移与拟合能力

- 在完整训练池固定 32 个去重 SM 窗口，覆盖多个块和标签范围，关闭增强，做训练内拟合检查；从同一初始化多次优化并画 RMSE 曲线。能拟合只说明可以记忆这部分标签，不能说明任务容易或可泛化。无法拟合优先查监督、优化、梯度/激活，不能直接判断输入没信息。
- 对 SM-only 完整基线追加冻结编码器和降低编码器学习率（如 0.1 倍）两个组；其余保持相同，以内层开发集选检查点。若训练误差稍高而独立验证更好，支持当前适配策略过拟合，但也可能包含优化稳定性收益。
- 原 train 内建立两类留出：严格按原生像元/地点组隔离、但同 5° 区域的“区域内”留出；完全按 5° 块隔离的“新区域”留出。不能把同观测重复窗口随机分开。匹配可用样本数量/气候/月分布并报告无法匹配的差异。
- 若地点无重复或每块样本太少，则不能实施时间外推/区域内对照，明确标记不可识别，不强制随机划分。
- 区域内好而新区域差支持空间迁移困难；两类都差需结合拟合曲线、输入和标签审计。原 validation 不重新随机切分，test 不参与。

## 8. 空间支持与标签噪声的独立审计

分组检查误差与标签时间偏移、窗口水体比例、已有影像异质性、产品有效性之间的关系；相关性只能定位，不能建立因果。
使用现有标签产品地理元数据确认 SMAP 足迹大小与窗口位置。现有 1.2 km 输入不能重建完整 SMAP 足迹的输入平均；不能用插值/复制标签制造额外监督，不能因“纯净子集”更准就认定质量原因（子集难度也变了）。
如果有同地点多日期或独立站点标签才追加时序/真值检查；没有则说明“固有噪声/足迹不匹配贡献未定量”。

## 9. 分阶段预算与交付

1. CPU：数据/原生观测审计、固定 splits/subsets、batch 序列、元数据时差汇总；GPU：一致性修复验证。
2. A0–A3 四组单 seed 短程筛查，随后关键配对完整训练、至少 3 seeds。先核对曲线能否比较，不因短程无差而排除负迁移。
3. B 三个比例（全量组可供后续复用）；C0/C1/C2/C2-control（协议完全相同才复用 C1 与 B 全量）；D 的冻结/低学习率分支按前述证据选择。
4. 数量曲线至少 3 个“子集抽样种子+训练种子”配对重复；最终报告分离种子不稳定与验证样本不确定性。资源限制下明确哪些仅单 seed 探索。
5. 第一阶段筛查为 4×2340=9360 个更新；四组完整 3 seeds 为 140400 个更新。GPU 小时用修复后 100 步实测吞吐和验证开销估算，不沿用未经核对的旧耗时。

建议独立目录 outputs/sm_causal_YYYYMMDD/ 保存：protocol.json（预登记目标和规则）、code_version、audit.parquet、split/subset manifests、batch_indices、run_matrix.csv、每次 expanded config/训练日志/checkpoint、逐窗口预测、配对差值和 report.md。
run_matrix.csv 至少含：run_id、hypothesis、seed、subset_seed、manifest_hash、loss/tasks、input_variant、normalization_hash、初始化哈希、batch schedule、steps、trainable params、checkpoint selection、status、GPU-hours。

结论按“支持/反对/证据不足”逐项写，不强行选唯一原因。没有完成单任务与数据量/时间对照前，不把 SM 表现较差归结为固有任务难度。

## 10. 与已有工具的关系

可复用：tools/validation/diagnose_multitask.py、summarize_multitask_diagnostics.py 的逐窗口评估、空间块 bootstrap、批次一致性和局部梯度探针。
需要实现：任务开关及冻结无损失 heads、固定索引训练流、分组嵌套子集、原生观测去重、时间过滤和支持交集、目标时差支路及等参数 control、按更新数固定的调度、内层开发集和配对实验汇总。
当前模型强制保留三个 heads，不能仅删除配置里的 WF/ET heads 实现单任务。正式实现须验证“关闭辅助损失不改变 SM 前向/标签序列”和“DDP 有效计数与单卡等价”。
