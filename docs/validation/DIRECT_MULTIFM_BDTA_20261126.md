# 多 FM 直接读取的 BDTA + MoTE

两组都从冻结的 OlmoEarth 与 AnySat 预训练权重开始，在相同的六轮监督训练中更新旁路、投影、时序池化、任务专家和预测头。沿用两个主干的四个出口及目标时间窗。初始 patch 使用有效来源均值。

## 每一级的双向适配

G2T 使用同一个任务查询直接读取各 FM 的独立特征图。每个头为每个来源预测四个采样偏移和对应的位置分数。学习组在参与的来源和位置上联合 softmax。等权组给每个参与的来源相同总权重，在来源内部对位置分数做 softmax。两组有完全相同的可训练参数，保留相同的空间采样自由度。两组在相同初始化、相同随机数下起步时具有相同的预测函数。

每个查询、每个头根据各 FM 的采样邻域有效掩膜确定来源是否参与。整路无观测贡献零；有效来源内部沿用单 FM 的掩膜与零填充边界插值。T2G 让每个来源独立回读该任务更新后的状态，共用同一个反向模块，再在有效中心对返回值取均值。MoTE 路由以本级有效来源的通用特征均值作为输入，混合任务专家。各预测头融合四级读出。[架构实现](../../hydrostate/models/cosa/direct_bdta.py)

## 对照协议

| 组别 | 各有效 FM 的总注意力 | 配置 |
|---|---|---|
| 学习组 | 取自来源与空间点联合 softmax | [直接读取](../../configs/hydrostate_joint_direct_bdta.py) |
| 等权组 | 两个有效来源各占一半，单一有效来源占全部 | [直接读取等权](../../configs/hydrostate_joint_direct_bdta_equal.py) |

训练 10,912 窗，开发验证 3,681 窗，完整独立测试 11,168 窗。种子 3407，训练有效 batch 10，开发与测试 batch 8。每轮验证，六轮后按开发 manual_joint_score 选一个检查点做完整测试。报告冰川水体、冰雪、陆地三类，洪水水体比例误差与 F1/IoU，站点 SM、ET 的 RMSE 与 Pearson R。产品一致性单列。
