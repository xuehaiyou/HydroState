# U-Net 对照本地验收（2026-11-02）

本记录对应本次未提交修改，不代表代码已同步到 HPC/A100 或正式训练已完成。

后续代码已提交并完成 HPC 排队安排，见 [HPC 提交记录](UNET_HPC_20261102.md)。

## 已实现

- 默认 277 输入通道，编码通道 64/128/256/512，三个下采样和对应跳跃连接。
- 默认共 8,202,446 个可训练参数（含 7 个损失方差参数），不加载基础模型权重。
- 相同七任务头、监督掩膜、陆地条件 SM、原始像元 PML 监督、覆盖闭合和总 ET。
- MTLoRA 与 U-Net 共享物理输出逻辑，保留 MTLoRA 参数路径。
- CLI、Shell/Slurm 配置选择、区域加载与性能测量入口均支持 U-Net；
  FM 的本地权重检查移到配置展开后的 Python 入口。
- 保持现有采样版本、已发布数组、归一化常数和训练统计的定义。

## 验证

环境：现有 Python 3.12 `hydrostate` 环境；`torch.cuda.is_available()` 为 False。

```bash
python -m pytest tests/retrieval tests/test_mtlora.py tests/test_training_launcher.py \
  tests/test_water_soil_coupling.py tests/test_training_hot_path.py \
  tests/test_temporal_model.py tests/regional/test_current_region.py \
  tests/regional/test_inference_runtime.py -q --tb=short --disable-warnings
```

**206 passed，33 warnings，37.94 s**。警告来自依赖接口，包括 Affine 运算弃用提示。
修改涉及的 Python 文件 Ruff 检查通过；三个修改的 Shell 文件语法检查及
`git diff --check` 通过。

新增测试验证：

- 默认宽度在 120×120 输入上输出 40×40；区域推理严格 checkpoint 读回一致。
- 缩小网络在合成七任务输入上的前向/反向、所有参数梯度和输出头梯度。
- CPU BF16 的 AdamW 更新及有限数值；GroupNorm 下单样本/批次预测一致性。
- 随机初始化可复现、种子改变权重，构造时不导入 FM 实现或访问预训练目录。
- 缺测位置填 NaN/Inf 不改变输出，整个传感器缺失仍可预测；无观测输出域正确掩膜。
- 观测陆地比例加权的 SM 聚合、覆盖闭合、非负 ET 和面积加权总 ET。
- 缺失 SM 标签只取消 SM 监督；时间槽顺序保留，异步/非中心查询拒绝。
- 缩短的年末目标窗口可用，季节编码遵循 UTC 日历年与闰年。
- U-Net 配置展开/重载保持当前契约，Slurm 路径在不存在 FM 目录时仍正确转交配置。
- FM 配置仍拒绝缺少或空的本地权重文件。

回归期间发现历史 `test_training_hot_path.py` 的模拟编码器缺少 `input_profile`。
在 `/tmp` 独立导出的原提交上复现了相同的 8 项失败后，仅补齐测试夹具属性；
未为生产编码器添加兼容回退。FM 区域测试的模拟权重目录也补齐了预检占位文件，
实际微型 FM 仍由原有模拟加载器创建。
