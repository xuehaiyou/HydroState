# 候选池与实时日期均衡验证（2026-10-23）

## 实现与运行参数

生产代码：`7d3dbe60c45ec4077ca879d5a08f31569bcc7328`。
统一配置：`configs/data/collection/retrieval.py`。

- 按 JRC 七个中心频率组建立轻量候选池，每组容量为剩余成功配额的 3 倍。
- 打乱跨区域候选点；优先配额缺口大的组，同组优先新地点和不足的气候区。
- 每个工作线程空闲时才选择日期，年份/月计数包括已完成与在途任务。
- 同等优先级随机选择，失败释放预占；同地点至多 4 个日期、间隔至少 40 天。
- 按各组成功保存数量补齐；覆盖质量、SM/ET 监督条件、原始分辨率存储保持不变。
- 试采 140 个样本，七组各 20 个；4 并发、2 CPU、0 GPU。
- HPC 数据目录：`/scr/u/xiaoz/HydroState/samples/retrieval_balanced_140_7d3dbe6`。

候选点在生成的有限池内随机抽取，不能解释成全球像素按面积等概率。
并发任务完成顺序会影响后续软均衡选择，具体复现以冻结代码、配置和已保存的
样本清单及源影像 ID 为准。
