# 双基础模型 BDTA + MoTE

以已完成六轮的单 OlmoEarth [BDTA + MoTE](BDTA_MOTE_20261125.md) 为参照，检验加入 AnySat 后的增益，以及逐位置、逐任务学习来源权重相对于固定等权的作用。比较使用已有训练、验证、测试清单。

## 结构

OlmoEarth 和 AnySat 完全冻结，包括 AnySat 的输入波段映射与最后一块。两路分别输出初始 patch 和四级特征。OlmoEarth 使用第 3、6、9、12 层，AnySat 使用第 2、4、6 个主块及终端跨模态块。两路独立投影到共同的 768 维空间，分别用同一个目标时段池化器聚合本路观测。初始任务状态是有效来源 patch 的均值。

每一级用任务上一层的状态作为查询，与各有效 FM 在该位置的特征计算余弦相似度。学习版在来源维做 softmax，所有层与任务共用一个从零初始化的可学习尺度。固定版对有效来源等权。单一有效来源的权重为 1，全部无效时该位置输出无效。每个任务用同一个融合特征参与 BDTA 的两个注意力方向，并给该任务原有的 MoTE 路由器提供上下文。Cover、SM、ET 共用这一规则。BDTA 更新后的任务状态递交下一级。每一级另由 MoTE 保留本任务专家的直接输出，并按当前场景学习借用三个任务专家的比例。每个预测头融合本任务四级 MoTE 的输出。

## 实验

| 配置 | 来源权重 | 直接比较 |
|---|---|---|
| [学习版权重](../../configs/hydrostate_joint_multifm_bdta.py) | 按任务状态、层特征和有效性选择来源 | 与固定等权对照隔离学习来源权重的作用 |
| [固定等权](../../configs/hydrostate_joint_multifm_bdta_equal.py) | 对有效来源平均 | 与单 FM 比较增加 AnySat 及其投影的整体效果 |

两组从相同的预训练基础模型与新任务层初始化，使用原有六轮短训协议。训练 10,912 个窗口，开发验证 3,681 个，独立测试 11,168 个。种子 3407，有效训练 batch 10，验证和测试 batch 8。每轮验证，按 manual_joint_score 选出的一个检查点做完整测试。分别报告冰川水体、冰雪、陆地，洪水水体比例及分类，以及站点 SM、ET 的 RMSE 和 Pearson R。产品指标只用于一致性比较。
