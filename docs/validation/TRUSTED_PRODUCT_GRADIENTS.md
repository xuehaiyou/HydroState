# 可信观测指导产品权重

本实验检验以人工 Cover、站点 SM 和站点总 ET 指导产品监督，能否提高留出样本的反演精度。只训练一个单 OlmoEarth + BDTA + MoTE。对照采用既有成绩，组批与损失均有变化，因此历史分差不能单独归因于动态定权。

沿用四级冻结 OlmoEarth、原划分和训练统计量。每轮 10,912 窗，种子 3407，物理 batch 为 10，末批为 2，每批一次优化器更新。每轮覆盖每个窗口恰好一次。每批有产品和 SM 站点，每个满批有人工 Cover。冰川点与洪水标签在同一窗口队列。80 个含 SMAP 的产品窗两两配到 40 批，212 个 ET 站点窗分散到有 PML 的 212 批。运行时有效输入和观测掩膜决定实际可定权量。

Cover、SM、ET 各占三分之一。每组按可信均方误差的三分之二与产品均方误差的三分之一合并。人工 Cover 按窗口等权，两种来源共用原有掩膜。SM、ET 沿用训练集尺度和物理支持。产品侧先按输出在有效观测上求均值，再平均该组有监督的输出。无可信观测时保留产品侧原系数。

每个产品误差对对应输出头的梯度与同组可信损失梯度做内积。每个输出用其有效观测的最大绝对内积归一，指数加权后恢复原质量权重总和。权重在正式反向传播中固定。每项的有效量及权重改变数逐轮写入工作目录。组权重是损失系数，实际梯度占比随数据变化。

使用同一开发集 3,681 窗逐轮选模，以最高 manual_joint_score 的检查点评估测试集 11,168 窗。验证和测试 batch 均为 8。分别报告冰川水体、冰雪及陆地，洪水比例与分类，以及站点 SM、ET 的 RMSE 与 Pearson R。产品一致性单列。

训练入口为 `python -m hydrostate.experiments.trusted_bdta REFERENCE RUN_DIR`。每轮清单摘要在 `sampling.json`，真实窗口显存、速度与定权计数在 `benchmark.json`，开发和独立测试结果分别在 `work/` 与 `final_test/`。
