# 冻结 CGC 的共享搭配与私有修正干预

假设：各任务在整块上决定两个共享专家的相对比例 q，在当地决定私有专家份额 λ，能够改善点位 SM 并保住站点 ET。用两个第 6 轮原版 CGC checkpoint、同一批开发验证窗口和原有观测算子检验。两份权重训练使用相同种子、不同 micro-batch。两次比较的验证集相同。

把三路 softmax 权重分解为 ((1−λ)q, (1−λ)(1−q), λ)。q 使用两个共享 logits 的 softmax，λ 取三个 logits 的 softmax 中私有专家的概率。两个决定分别用原门控读取整块有效均值或当地状态，覆盖、SM 和 ET 同时采用相同规则。原版三路 softmax 另作未修改的参照。整块/整块与原版的逐条站点预测最大绝对差均小于 0.00002（各任务原单位），与浮点运算顺序带来的差异一致。

SM 为 1,158 个窗口、1,639 条观测、144 个空间组；ET 为 446 个窗口、446 条观测、37 个空间组。整块/局部相对原版的 SM RMSE 差值分别为 −0.000189（空间组配对 bootstrap 95% 区间 −0.000351 至 −0.000044）和 −0.000138（−0.000209 至 −0.000068）。全局部配置的 SM RMSE 还略低，因此共享搭配本身局部化也可能贡献一部分收益。对应的 ET RMSE 差值分别为 +0.00643（+0.00251 至 +0.01175）和 −0.00388（−0.01161 至 −0.00018）。同批站点上的方向不一致，统一替换无法稳定保住最佳 ET。ET 输出同时经过覆盖与分量通量路径，此实验未拆分两者。

作业 4488429（HKU）与 39166（地理系）分别位于对应数据根目录的 `experiments/cgc_gate_factor_2fbf0d8`。两者均加载既有权重，运行 `python -m hydrostate.experiments.cgc_gate_audit ... --factorized`，再运行 `cgc_gate_report` 和 `station_generalization`。逐观测预测、2,000 次空间组 bootstrap 及逐站结果分别存于 paired.parquet、gate_effects.csv、station_summary.csv 和 per_station.csv。

整块/局部相对反向对照的 SM RMSE 改变量，历史为 −0.000178（95% 区间 −0.000328 至 −0.000041），地理系为 −0.000100（−0.000167 至 −0.000034）。站内去均值后的 SM R 相对原版分别从 0.52731 升至 0.52901、从 0.51014 升至 0.51169；相应差值区间均包含零。结论为私有份额的局部化对 SM 原单位误差有小幅、可重复的作用；对站内时间变化的增益仍不确定。未满足两份权重均保住 ET 的条件，本轮到冻结权重干预为止。
