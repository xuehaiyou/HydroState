# OlmoEarth 上的 BDTA 与 MoTE 联合反演

本实验检验完全冻结 OlmoEarth、只在四级旁路进行任务适配时，能否保留人工覆盖标签和站点 SM、ET 的验证精度。对照采用既有的单 OlmoEarth RUTaL 与 D²MoE 实验。[AAAI 2026 原文](https://doi.org/10.1609/aaai.v40i14.38171) · [既有开发验证](MULTIFM_RUTAL_20261125.md)

| 模块 | 实验实现 |
|---|---|
| 通用主干 | OlmoEarth v1.2 Base 全部冻结，保持 eval 模式并在 no_grad 下前向。输出初始 patch 和第 3、6、9、12 层。 |
| 双向旁路 BDTA | 按式 3–8 先让任务查询通用特征，再让通用特征查询刚生成的任务特征。每个方向各有带残差的稀疏交叉注意力与 FFN。方向内的注意力、FFN 和通道投影在任务间共享。两个方向各有任务专属的残差适配器。两向结果相加、升维后进入下一级，主干始终只读。 |
| 任务混合 MoTE | 按式 9–11，每级先投影各任务特征，再由该级的通用特征为每个接收任务产生全图块权重。分数和噪声尺度各有两层 MLP，训练使用高斯噪声，验证和推理使用确定性权重。每级每个接收任务有独立的逐通道缩放系数，零初始化。保留自身专家的直连路径，四级混合结果拼接、投影、分组预测。 |
| 数据适配 | 使用与 RUTaL 相同的可训练目标时间查询、观测质量和独立掩膜。所有源任务专家在接收任务的目标时段计算。路由全局池化仅计入有效位置。Cover、SM、ET 三组共七个内部输出，沿用覆盖闭合及总 ET 定义。 |
| 与原文的实现差异 | 原文的 Swin 有四个空间尺度。OlmoEarth 的四级特征在同一网格，因此省略跨尺度 patch 合并和式 9 的空间上采样。首级宽度为 768，旁路按原文缩至 192。原文未完整指定的微架构采用已有的六头、每头四点可变形注意力、等宽 FFN、瓶颈宽度为旁路的四分之一。最终预测按已有契约插值到 30 m 网格。 |
| 比较协议 | 复用 D²MoE v2 六轮展开配置的产品、站点和两种人工 Cover 样本。训练 10,912、开发验证 3,681、完整测试 11,168 个窗口。种子 3407，训练有效 batch 10，验证和测试 batch 8。按开发验证 manual_joint_score 选一个检查点做完整测试。分别报告冰川水体、冰雪、陆地以及洪水 F1/IoU/比例误差、站点 SM/ET RMSE 和 Pearson R。产品指标仅供参考。 |

配置入口为 [hydrostate_joint_bdta.py](../../configs/hydrostate_joint_bdta.py)。启动入口为 `python -m hydrostate.experiments.dense_adaptation bdta <平台原六轮配置> <新输出目录>`。一个运行依次执行真实数据显存探测、六轮训练、开发验证选模和最终测试。
