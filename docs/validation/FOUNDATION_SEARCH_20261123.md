# 三种基础模型架构的站点与人工 Cover 配对实验

固定参照为 [B 的六轮实验](MANUAL_COVER_TOP3_RESULTS_20261123.md)。从 HPC2021 已执行的
`manual_cover_top3_20261122/training/B/epochs_1_6/config.py` 派生运行配置。
复用训练/验证清单 10,912 / 3,681 个窗口、预计算统计量、七个输出、空间支持损失、
人工 Cover 监督与联合选模，种子 3407，有效 batch 10。开发验证比较同一所选 epoch
的站点 SM/ET RMSE、Pearson R，冰川三类分开的比例误差、F1 和支持数，以及洪水
水体比例误差、IoU 和召回率。留出的完整测试集待模型定型后使用。

## 第一版实验（提交版本 `79f8407`）

| 实验 | HydroState 中实际执行的变化 |
|---|---|
| DiTASK | 在 OlmoEarth 各层 Q/K/V/O 投影上对冻结的奇异谱做单调位置变换。连续分段仿射速度场用缩放平方近似积分，零速度对应恒等变换。第 4/8/12 层输出 Cover、SM、ET 专属分支。复用 B 的时间融合权重结构与任务读出。实现使用原生 PyTorch 和一次性 SVD，属于论文机制的迁移。 |
| D2MoE | 冻结 OlmoEarth 主干，全部注意力层加入 rank 16 共享更新。三个深度出口分别以有效 token 的均值进行任务条件路由，每个样本从四个 rank 4 专家中选两个，对 Q/K/V/O 加权。未适配的冻结主干额外前向提供最深层先验，各任务通过通道门控注入三个深度，再使用 B 的读出。三个同网格深度和先验融合均为 OlmoEarth 适配。 |
| AnySat | 使用官方 AnySat Base 权重及代码 `5f6f475e1a22ce5e3a56a5b18f4ed6d24eca2a4a`。每个 8 天槽保留实际可用传感器，使用遮罩与年内日序。按官方顺序初始化光学波段映射，S2 的两个额外波段可通过可训练线性输入映射参与；S1 第三通道初始化为标准化雷达对比。使用全部 11 个 Landsat L1 TOA 通道。输入归一化沿用 HydroState 的已存标度并重新居中，不主张与上游训练分布相同。每槽提取两层中间特征及最终融合特征，槽间聚合由 B 的时间解码器承担。训练输入映射和末端跨模态块，其余 AnySat 权重冻结。 |

DiTASK 和 D2MoE 对各任务出口分别调用同一套时间融合参数。AnySat 改变了主干、
预训练权重、槽内模态融合方式及可训练参数范围，结果代表整套方案。
同一传感器、时间和标签清单可用于三个候选，未另设仅 S1/S2 的基线。

参考 [DiTASK 官方实现](https://github.com/ipsitmantri/DiTASK)、
[AnySat 官方实现](https://github.com/gastruc/AnySat)、
[D2MoE 论文](https://arxiv.org/abs/2611.02769)。

## 第二版 DiTASK 与 D2MoE

原先统一用 B 的第 4、8、12 层和 B 的解码器，适合比较三出口设置下的改动，但也改变了两篇方法的结构。第二版恢复各自的四个阶段出口和预测头。层号均从 1 开始。

| 部位 | DiTASK | D2MoE |
|---|---|---|
| 阶段如何确定 | 将 OlmoEarth 的 12 层等分为四段，在第 **3、6、9、12** 层末产生任务特征，使两个候选在相同深度分支。作者 Swin-T 配置的出口为第 2、4、10、12 层。 | 原文要求在四个阶段的最后一个注意力块做任务路由。将 OlmoEarth 的 12 层等分为四段，在第 **3、6、9、12** 层路由。等分是本项目的映射选择。 |
| 共享与专属参数 | 在所有层的 Q/K/V、输出投影和前馈网络两个线性层使用作者选用的 `difw==0.0.29`。固定变形边界，采用 Kaiming 初始化、64 个共享区间、4 个专属区间与 0.05 dropout。每层 Q/K/V 共用变形参数和输入 dropout 掩膜，各自变换自己的奇异谱。仅在阶段末为输出投影及两层前馈网络分出任务专属谱变形。 | 全部注意力的 Q/K/V/O 使用 rank 16 的共享 LoRA。每个阶段末按任务汇总有效 token，从 16 个 rank 4 专家中选择 8 个，仅计算选中专家。共享路径和任务路径分开，任务路径使用冻结投影加专家更新。缩放为 α/r，α=4，dropout 为 0.05。 |
| 特征融合与预测 | 各任务将四个深度分别投影至 18、36、72、144 通道，再拼接。HRNet 读出使用 1×1 扩展至 1,080 通道、BN、ReLU、1×1 输出和双线性插值。 | 每个阶段对同一输入另外运行一次关闭适配器的冻结块，生成该深度的先验。384 通道 SPI 为每个像元计算四个深度的任务权重，另行融合四级先验，再拼接细化。每组任务以 1×1 投影输出，经双线性插值到目标网格。 |

DiTASK 使用 OlmoEarth，四个特征图共享一个空间网格。Swin 的窗口注意力、逐阶段空间降采样和对应的分辨率金字塔来自原主干。训练采用作者配置中随层深由 0 增至 0.2 的随机深度。冻结投影的 SVD 在本实现中只计算一次，作者代码在前向时计算。对应依据见 [DiTASK 原文](https://arxiv.org/abs/2502.06029)、[作者的 Swin-T 配置](https://github.com/ipsitmantri/DiTASK/blob/1ef40ae9d2188be6c89169c618be317a4562d99e/configs/ditask/ditask_tiny_448_r64.yaml)、[谱变形实现](https://github.com/ipsitmantri/DiTASK/blob/1ef40ae9d2188be6c89169c618be317a4562d99e/models/lora.py)和[预测头实现](https://github.com/ipsitmantri/DiTASK/blob/1ef40ae9d2188be6c89169c618be317a4562d99e/models/seg_hrnet.py)。

D2MoE 的冻结先验来自 OlmoEarth。三个任务组各有路由器，屏蔽缺测 token 后计算场景均值。路由、先验融合和预测头依据原文式 1–23 实现；专家数与激活数采用作者消融中表现最好的设置。D2MoE 的数值检查以公式为参照。[D2MoE 方法与消融](https://arxiv.org/html/2611.02769v1)

两个模型均在解码器中引入目标时间。每个深度先按目标窗口的中心时刻、时长、各观测与窗口的时间差以及观测质量，对五个 8 天槽的有效观测逐位置加权，再融合四个深度。DiTASK 的谱变形参数由训练学习；D2MoE 的专家由任务路由器根据有效输入 token 选择。两者的编码器分支均不直接读取目标窗口。D2MoE 的四级冻结先验也按同一目标窗口聚合。

Cover、SM、ET 三组分别输出 3、1、3 个通道，对应覆盖比例闭合、陆地 SM 和三类表面 ET。站点、人工覆盖和产品保留各自的监督尺度、损失与权重。训练预算、验证和选模沿用 HydroState 的短训协议。

### 验证范围和实验版本

- 同权重、同输入和同变形参数下，CUDA FP32 中与作者 `DiTASKLinear` 对照，一个 32×32 投影的共享和专属输出最大绝对差为 1.24×10⁻⁵，变形参数梯度最大绝对差为 7.31×10⁻⁷。D2MoE 的选中专家加权和与显式求和一致，未选中的专家在该批次的梯度为零。
- 在提交 `1fd5cff`（DiTASK 出口为第 2、4、10、12 层）上，两个正式配置均载入本地 OlmoEarth v1.2 Base 的全部 12 层，在五槽合成小图块上完成一次 CUDA BF16 损失前向与反向，梯度有限。57 项相关测试通过，包括两个新模型的产品、站点 SM/ET 和人工 Cover 监督梯度检查。DiTASK 此次通过 difw 的 PyTorch 路径运行，未测量 HPC 上的原生扩展吞吐。
- 统一四等分后，两套正式配置都在第 3、6、9、12 层生成任务特征。用真实预训练主干、固定的五槽合成输入做两次 GPU 前向，第二次仅将目标窗口整体后移 8 天。两个模型在四个出口的编码特征均逐值相同，各自七个最终输出均有变化。同期 32 项相关回归测试通过。
- 第二版训练入口使用独立的 `ditask_v2/` 和 `d2moe_v2/` 目录。DiTASK 环境需要安装项目可选依赖 `.[ditask]`。第一版训练及验证结果仍对应提交 `79f8407`。
