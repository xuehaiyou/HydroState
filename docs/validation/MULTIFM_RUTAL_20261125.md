# 双基础模型 RUTaL 与同口径开发验证结果

OlmoEarth 在第 3、6、9、12 层产生特征，AnySat 在第 2、4、6 个主块及最终跨模态块产生特征。两者的初始 patch 有效均值启动四级阶梯。在每个任务、每级、每个可变形采样位置，比较同一个查询与两路键的余弦相似度。一个全阶梯共享的可学习尺度从零开始。对有效来源做 softmax，位置权重继续使用原 RUTaL。中心调制使用相同的来源选择规则。固定等权组对每个位置的有效来源取均值。

两项配置分别为 [学习权重](../../configs/hydrostate_joint_multifm_rutal.py) 和 [固定等权](../../configs/hydrostate_joint_multifm_rutal_equal.py)。训练入口复用 dense_adaptation，分别指定 multifm_rutal 或 multifm_rutal_equal，并提供既有平台 D2MoE v2 的六轮展开配置和独立输出目录。两组均从相同的预训练主干初始化。

## 提交与验收

训练提交版本为 `1ec8a3c`。地理系 HPC 的 `GEOG-HPC-GPU` 分区使用两份独立的单 GPU 作业。学习来源权重为 `40545`，固定等权为 `40546`，输出目录分别为 `/geogfs1/groups/geog_geors/xiaozhen/HydroState/experiments/multifm_rutal_1ec8a3c/multifm_rutal` 和同级的 `multifm_rutal_equal`。两者在同一次 GPU 分配内依次执行真实数据 batch 预检、连续六轮训练、逐轮验证和验证选模后的完整测试。提交时两者均为 PENDING。

两份展开配置分别与平台原六轮配置逐项核对了训练/验证/测试数据、统计、评估器、优化器、随机种子和选模设置。地理系与原 HKU 平台的十二份拆分选择清单和一份人工来源清单共十三份，SHA-256 均逐文件一致。只有训练 micro-batch 和相应梯度累积按实际显存选择。单 FM 退化通过了四级状态、三个任务读出、七个物理输出的一致性检查，并测试了初始化等权、全缺测以及两路特征和来源尺度的反向梯度。
